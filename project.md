# Goal
A plugin dedicated for visualizing Machine Learning logic/workflow that supports Claude Code and Github Copilot
# Requirements
1. Visualizing the complete logic/workflow in diagram
2. The diagram should be interactive. For example, clicking on a module/connection leads to the corresponding code.
3. On diagram the potential issues should be marked. For example, a symbol for low risk ones, yellow warning triangle for medium ones and red exclamation mark for high ones
4. The UI/UX and design should be beautiful while being clear, intuitive and user-friendly
