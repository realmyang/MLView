# contracts/

Frozen interfaces every MLView component codes against. Read-only once written.

- `graph.schema.json` - the MLGraph JSON Schema (Draft 2020-12). Mirrored byte-identically at `analyzer/src/mlview/schema/graph.schema.json` and carried to the vendored cores by `tools/sync-core.py`.
- `graph.sample.json` - the hand-authored golden document (`python -m mlview analyze --demo` emits exactly this). It is never regenerated by anything, ever.
- `scope.cases.json` / `scope.expected.json` - the scope parity battery: 13 projecting cases, 7 error cases and the promoted fuzz counterexamples, computed over the frozen golden. `analyzer/tools/gen_scope_fixtures.py --check` regenerates and byte-diffs without writing.
- `validate_sample.py` - the schema plus the ten invariant groups, run over every emitted and every generated document.
- The textual contracts - conventions, the graph document, the CLI, the in-process API, the rule API, the scope grammar and projection, the diff overlay, the webview message protocol, the renderer API, the viewer DOM contracts, the MCP tools, the VS Code contributions, the Claude Code plugin, the fixtures, packaging and the acceptance gates - live in `../docs/CONTRACTS.md`, **MLView Contracts v1.1**.

v1.1 folds the v1.0 spec and its 63 amendments into one versioned document; §18 there maps every old amendment number (`§10 A1`, `§11.25`, ...) to the section that now carries it, and §17 records the statements a later amendment overturned. The verbatim v1.0 text is kept at `../docs/archive/CONTRACTS-v1.0-amended.md`.
