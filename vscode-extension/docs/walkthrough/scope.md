# Refine with your assistant

Filter and explore the existing diagram locally. To investigate something the
assistant has not inspected, use Refine and paste its prompt into that same
assistant. Ask for a new revision preserving stable IDs and naming the current
revision as its parent. The panel refreshes after a valid publication.

Save source edits before regeneration. Invalid, stale, or superseded updates
retain the last valid diagram. No model runs just because you save or filter.
