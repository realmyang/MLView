# MLV803 - Whole model pickled, or torch.load left unrestricted

| | |
|---|---|
| **Severity** | `low` - blue circle - hygiene, reproducibility, portability, or a question worth asking |
| **Frameworks** | torch |
| **Base prior** | 0.95 |
| **Rule version** | 1 |
| **Tags** | `deliver`, `portability` |
| **Absence rule** | no |
| **Enabled** | yes |

## Why it matters

A pickled module stores the class path rather than the weights, so the checkpoint stops loading the day the file is renamed - and an unrestricted torch.load executes whatever the pickle tells it to.

## How it is detected

`torch.save(<MODEL>, path)` where the saved expression contains no `.state_dict()`, and `torch.load(...)` with neither `map_location=` nor `weights_only=`.

## False positives it avoids

- `torch.save(model.state_dict(), path)` and a dict of state dicts.
- A saved value that carries no `MODEL` tag - the rule records an `untagged_dataflow` note instead of guessing.

## How to fix it

Save torch.save(model.state_dict(), path) and load it back with torch.load(path, map_location="cpu", weights_only=True).

## Example that fires

`analyzer/tests/fixtures/rules/MLV803_bad.py`

```python
"""The whole module is pickled rather than its state_dict, and the checkpoint is
read back with neither map_location= nor weights_only=."""
import torch
import torch.nn as nn


class Net(nn.Module):
    def __init__(self, features: int = 16, classes: int = 3) -> None:
        super().__init__()
        self.head = nn.Linear(features, classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.head(x)


def save(model: nn.Module, path: str = "runs/best.pt") -> None:
    torch.save(model, path)


def restore(path: str = "runs/best.pt") -> nn.Module:
    return torch.load(path)
```

## Example that does not

`analyzer/tests/fixtures/rules/MLV803_good.py` - the nearest false-positive trap this rule has to survive.

```python
"""The trap: the same two calls on the same model, spelled the safe way - the
state_dict is what is pickled, and the load is pinned to the CPU with
weights_only=True. Matching torch.save/torch.load alone would fire here."""
import torch
import torch.nn as nn


class Net(nn.Module):
    def __init__(self, features: int = 16, classes: int = 3) -> None:
        super().__init__()
        self.head = nn.Linear(features, classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.head(x)


def save(model: nn.Module, path: str = "runs/best.pt") -> None:
    torch.save(model.state_dict(), path)


def restore(path: str = "runs/best.pt") -> nn.Module:
    model = Net()
    model.load_state_dict(torch.load(path, map_location="cpu", weights_only=True))
    return model
```
